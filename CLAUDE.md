# Yuliya Verhoglyad — страница-визитка

Личная страница-визитка. Цель одна: чтобы посетитель написал в Telegram (https://t.me/yuliyaverhoglyad).
Подробная спецификация макета — в `design.md`, сверяйся с ней.

## Стек и файлы
- Страница: обычный HTML и CSS, без фреймворков и сборщиков. JS в браузере — только свой, в `script.js`.
- Сервер: Node.js на встроенном модуле `http`, без Express. Единственная зависимость — `pg`
  (протокол PostgreSQL руками не пишут). Для Telegram библиотека не нужна: в Node есть `fetch`.
- `index.html` — страница, `styles.css` — все стили, `script.js` — переводы и форма,
  `server.js` — сервер, `images/` — картинки.
- Пути к файлам всегда относительные (`styles.css`, `images/yulia.webp`), без `/` в начале и без абсолютных адресов.
  Единственное исключение — `og:image`: мессенджеры требуют полный адрес `https://senorita-git.github.io/...`.
- Сайт опубликован через GitHub Pages: https://senorita-git.github.io (репозиторий `Senorita-Git/senorita-git.github.io`, ветка `main`).

## Форма заявки и секреты
- Форма работает только там, где есть сервер, то есть на Railway. На GitHub Pages `script.js`
  прячет её и возвращает кнопкам ссылку в Telegram.
- Поля проверяются дважды: в браузере ради удобства, на сервере ради надёжности.
  Правила должны совпадать — при правке меняй их в обоих местах (`script.js` и `server.js`).
- Сервер отвечает ключами сообщений (`errNameEmpty` и подобными), а переводит их браузер.
  Поэтому новый текст ошибки добавляется в словари `script.js`, а не в `server.js`.
- Секреты читаются только в `server.js` через `process.env` и никогда не попадают в браузер:
  `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
- В `index.html` стили и скрипт подключаются с номером версии (`styles.css?v=2`).
  **Меняя `styles.css` или `script.js`, увеличивай номер** — иначе у вернувшихся посетителей
  останется старая версия из кеша браузера, и новая страница будет работать неправильно.
- Сервер отдаёт наружу лишь разрешённые файлы (`index.html`, `styles.css`, `script.js`, `images/`).
  Добавляя новый файл для страницы, впиши его в этот список в `server.js`, иначе он вернёт 404.

## Цвета
Задавай только через переменные из `:root` в `styles.css`, новые цвета не придумывай.

| Переменная | Цвет | Для чего |
|---|---|---|
| `--bg` | #F7F8EF | фон страницы |
| `--pistachio` | #E0ECC8 | первый экран, наведение |
| `--pistachio-press` | #D0DEB3 | нажатие |
| `--green` | #37482D | имя, кнопки, активный язык |
| `--yellow` | #FBF1C7 | контакты, паспарту фото |
| `--card` | #FCFCF8 | фон карточек |
| `--olive` | #EDEECF | третья карточка |
| `--text` | #201F1D | основной текст |
| `--text-65/60/72` | #201F1D при 65/60/72% | подписи / неактивные языки / описания |
| `--gold` | #B68235 | номера, подчёркивания, фокус |
| `--gold-dark` | #7D5411 | кикеры |
| `--gold-deep` | #5A3B0A | текст на жёлтом фоне |
| `--line` | #201F1D при 16% | линии и обводки 1px |

Без теней, градиентов и сплошных заливок золотом — цвет через линии, обводки, подчёркивания.

## Шрифты (Google Fonts)
- Заголовки: **Cormorant Garamond** (`--serif`), 400 и 600. Жирный 700 не используем.
- Текст: **Lora** (`--sans`), 400.

## Языки
- Три языка: UA (`uk`), RU (`ru`), EN (`en`). **По умолчанию — украинский.**
- В HTML сразу пишем украинский текст и помечаем его `data-i18n="ключ"`; переводы добавляем в `script.js` во все три словаря.
- Имя, контакты, «Telegram», «GitHub» и год не переводятся.
- К посетителю обращаемся на «вы».

## Телефон
- Всё должно нормально выглядеть на телефоне: проверяй на ширине 390px и 320px, без горизонтальной прокрутки.
- Правила для телефона — в `@media (max-width: 600px)` в конце `styles.css`.
- Зона нажатия у кнопок и ссылок не меньше 44×44px.
